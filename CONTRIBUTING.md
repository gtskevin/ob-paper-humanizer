# Contributing

1. Fork the repo
2. Create a feature branch: `git checkout -b my-feature`
3. Commit: `git commit -m 'Add feature'`
4. Push: `git push origin my-feature`
5. Open a Pull Request

## Good First Issues

Look for issues labeled `good first issue`.

## What to Contribute

- **New AI pattern categories** — Found a pattern not in the 17 categories? Open an issue with examples.
- **Journal calibrations** — Add voice characteristics for journals not yet covered.
- **Test cases** — Before/after examples from published OB papers (pre-2023) are gold.
- **Bug fixes** — If the skill over-corrects or under-corrects, file an issue with the text and expected behavior.

## Guidelines

- Keep the surgical principle: edits should remove AI fingerprints without changing meaning.
- Never add patterns that encourage fabrication or misrepresentation.
- Test against real OB papers when possible.
